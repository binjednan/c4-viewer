# عارض مخططات C4

## رابط الفتح المباشر

[افتح مشروع C4](https://binjednan.github.io/c4-viewer/)

عارض للمخططات الأصلية وربط تمثيلات العنصر بين اللوحات باعتماد المستخدم.

- واجهة عربية للجوال، بأدوات لمس ومظهر فاتح وداكن.
- قاعدة المشروع الحالية نفسها، مع تحميل موارد المخططات والخطوط عند الحاجة.
- تُحفظ الاختيارات والاعتمادات محليًا في المتصفح على الجهاز. «تصدير الاعتمادات» ينتج ملف الإجابات للتسليم؛ لا توجد مزامنة تلقائية إلى GitHub.
- المعرّفات الحالية مراجع داخلية مؤقتة.

الموقع منشور عبر GitHub Pages. نسخة الموقع وموارده محفوظة في الإصدار `c4-mobile-2026-10-20` وتُنشر باستخدام GitHub Actions بعد فحص SHA256.

## الاستخدام من الجوال

1. افتح الرابط؛ يُفتح المشروع تلقائيًا.
2. من «الأدوات» اختر «اختيار»، ثم انقر على تمثيل العنصر. يمكن استخدام «تحديد بإطار» أو ضغطة مطوّلة لاختيار خط.
3. اجمع التمثيلات المقابلة من اللوحات، ثم اضغط «اعتماد الربط» في «الاختيارات».
4. من «الأدوات» استخدم «تصدير الاعتمادات» لتسليم ملف القرارات.

السحب بإصبعين يحرك المخطط، والتقريب أو التبعيد بينهما يغيّر الزوم. خيارات المظهر: حسب الجهاز، فاتح، داكن.

فُحصت الواجهة بمحاكاة اللمس على المقاسات 390×844 و320×700 و844×390 في Chromium، وشمل الفحص استعادة الاختيارات بعد إعادة التحميل. فُتح الموقع المنشور وتحقق عرض لوحة A103 وفهرس 250 صفحة. لم يُجرَ اختبار على iPhone فعلي أو Safari.
